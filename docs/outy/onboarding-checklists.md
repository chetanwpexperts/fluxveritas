# Onboarding Checklists

Checklists that make sure every new hire gets set up (accounts, documents, introductions).

## Who can use it
HR, admins and owners create and manage checklists. New hires see their own tasks.

## Steps
1. Go to `/hr-onboarding` (there is no sidebar link yet).
2. Click **New checklist**, pick the new employee and a due date.
3. Add tasks (for example "Laptop issued", "Sign NDA"), each with an owner and due date.
4. Tick tasks off as they are completed; the checklist completes when all are done.
