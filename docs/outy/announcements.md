# Announcements

Company news posted to everyone, a department or a team.

## Read announcements
Open **Announcements**. Unread ones are marked; use **Mark all as read**.

## Post an announcement (owners, admins, team leads)
1. Open **Announcements** and click **New announcement**.
2. Write a title and message.
3. Choose the audience: whole organization, a department, or a team.
4. Set priority (normal or urgent), optionally **pin** it to the top and set an expiry date.
5. Post.
