# Tasks and Sprints

## Tasks
Work items with an assignee, priority, due date and status.
Statuses: backlog, to do, in progress, in review, blocked, done, cancelled.

### See your tasks
Open **Tasks** in the sidebar, or **Tasks → My tasks**.

### Create a task
1. Open **Tasks** and click **New task**.
2. Add a title, project, assignee, priority, due date and estimate.
3. Save. Each task gets a ticket number.

### Update a task
Open the task to change its status, edit details or add comments. Marking a task **done** records the completion date, which counts toward increment scores.

## Sprints
Time-boxed groups of tasks for a project.
1. Open **Sprints** and click **New sprint** (name, goal, project, dates).
2. Add tasks to the sprint.
3. Click **Start** when the sprint begins and **Complete** when it ends.
