# GitHub sync

Brings commits and pull requests into OutraqHQ for engineering teams. Optional — other departments don't need it.

## Steps
1. Each developer adds their GitHub username under **Profile → GitHub**.
2. An owner or admin sets up GitHub under **Settings → GitHub**.
3. Add the GitHub owner and repository to the project (see "projects").
4. On the **Dashboard**, click **Sync GitHub** (owners, admins and team leads).

GitHub activity counts toward increment scores only for technical roles.
