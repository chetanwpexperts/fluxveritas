# Projects

Projects group tasks, sprints, blockers and GitHub activity.

## Who can use it
- Everyone can view projects.
- Owners, admins and team leads can create and edit projects.
- Only owners can delete projects.

## Create a project
1. Open **Projects** and click **New project**.
2. Enter the name, description and dates.
3. Optional: add the GitHub owner and repository to track code activity (see "github-sync").
4. Save.
