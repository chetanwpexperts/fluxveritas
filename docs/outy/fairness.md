# Fairness Engine

Checks for patterns that can make work unfair — uneven workload, blockers left open, people stuck in meetings — so managers can act early. **Pro plan.**

## Who can use it
Owners, admins and team leads.

## Steps
1. Open **Fairness** in the sidebar.
2. Click **Run analysis**.
3. Review each flag and its evidence.
4. **Confirm** the flag if it's real, or **Dismiss** it if there is a good reason.

## Notes
- People on approved leave are not flagged.
- Flags are suggestions for a manager to review — nothing changes automatically.
